Tested `codex/monday-demo-ready` on the Mac mini with Python 3.12.13, the pinned `.venv`, a local Streamlit server at `http://localhost:8501`, and gstack's Chromium browser. The model checks used `HF_HUB_OFFLINE=1`; the demo launch scripts also force offline model loading. This is a local application check, not a field-accuracy study or a test on the Windows 10 laptop.

## Fixes made during QA

- Manual NDVI controls retained values from a previous tile after a new sample or image pair was classified. The sample, upload and scenario paths now synchronize those controls with the freshly computed statistics before widgets render. An AppTest regression check switches from severe to healthy and checks every feature.
- The first scenario was labelled `Pristine Field (Healthy)` even though its healthy-ground-truth canopy tile is predicted Moderate Stress. It is now `Pristine Leaf, Canopy Warning`, which matches the actual mixed-signal display.

## Verification and remaining limits

`python -m unittest discover -s tests -v`: 5 tests passed, including real paired-image/manifest agreement, bad-band rejection, LFS-pointer recovery and Streamlit state checks. `python test_core.py` passed model, OOD and fusion checks. `HF_HUB_OFFLINE=1 python scripts/verify_environment.py --offline --full` passed package, artifact and reference-inference checks. The `core.py` SHA-256 remained `5c2b3f00a8681f58d3a1f4381fff6b988d07f11f3646201612d7ecdf11bc375d`.

The forest predicts **none of the six bundled healthy-ground-truth tiles as healthy** (three severe, three moderate). This is a material accuracy limitation, not an app malfunction; see [model evaluation](MODEL_EVALUATION.md) and [next accuracy plan](NEXT_ACCURACY_PLAN.md). Module 1's ImageNet sanity heuristic also warned on the Apple Black Rot sample although its classifier prediction was correct. The report-download click, every scenario/sequence, camera upload on a real device, and the actual Windows 10 laptop were not exercised in this Mac browser run. The Windows laptop remains the release gate in [Windows demo checklist](WINDOWS_DEMO.md).
